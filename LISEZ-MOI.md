# Portfolio — Emma Di Gesaro

Site statique (HTML/CSS/JS), sans aucune installation nécessaire.

## Structure
- `index.html` — page d'accueil (concept bleu)
- `projets/` — les 7 pages projet, dans l'ordre du menu :
  rexona, avene, shiseido, air-france, edf, fdj, adidas
  (chaque dossier contient sa page et ses visuels dans `img/` ou `videos/`)
- `blog/` — Personal Editorial Writing (PEW), les articles
- `autres-concepts/` — les pistes de page d'accueil non retenues
  (cahier de brouillon, accueil noir, typo avec personnage BD)

## Voir le site
Ouvrir `index.html` dans un navigateur. Pour que les vidéos et polices
se chargent bien partout, lancer un petit serveur local depuis ce dossier :
`python3 -m http.server` puis aller sur http://localhost:8000
